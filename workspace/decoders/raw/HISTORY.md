# raw 历史

> 只记 DLL 对外可见的变化。ABI 版本史见 `解码器开发规范.md` §九。
> 本档是 tier + 引擎：显影链在 `workspace/decoders/raw/src/lib.rs`，不在单库。

## 0.5.3 — 2026-10-29 — abi 6

- **修复**：静态格式的 `IvRenderOut` 现在显式回填 `frame_count = 1` / `frame_delay_ms = 0`；
  宿主复用输出缓冲时不会残留上一张动图的帧数。
- **修复**：单槽缓存指纹增加中段采样，长度与首尾相同的两张 RAW 不再互相串图。
- **未变**：后缀集合、显影算法、`rawler` 0.7.2、能力位均不变。
- **升级建议**：可选升（只修缺陷）。

## 0.5.2 — 2026-10-28 — abi 6

- **变更**：ABI 代次前移到 **6**。v6 是**纯加法**（新增可选导出 `iv_render_region` 与新结构体 `IvRegionReq`），既有导出签名与结构体布局**逐字节未动** ⇒ 本档的解码行为与上一版完全一致。
- **未变**：后缀集合、像素格式、识别与容错逻辑均不变；本档不提供任何矢量能力。

## 0.5.1 — 2026-10-28 — abi 5

- **修复**：`MAX_PIXELS = 64 MP` 现在在查询与渲染两个入口都检查，宿主跳过查询直接 `iv_render` 也无法绕过上限。
- **验证**：本地 10 张真实 RAW 冒烟通过；RW2 需带扩展名调用，X100V RAF 是偏暗样本而非空解码。
- **未变**：`rawler` 仍固定 0.7.2；没有新增后缀、没有改变显影算法。

## 0.5.0 — 2026-10-27 — abi 5

- **变更**：DLL 自述增加可扩展 `iv_metadata()`；包格式改为 ZIP + 同版本许可证目录。
- **版本延续**：0.4.0 的 rawpx 并入、29→40 后缀、显影链/分箱/画幅/色彩矩阵改动随本版发布；
  细节见 git 提交记录。
- **认领**：40 个后缀、成员与能力位不变。
- **合规**：`rawler` 固定 **0.7.2**、LGPL-2.1，单 DLL 静态链接；发布 ZIP 含 LGPL-2.1 与
  `SOURCE-OFFER.md`（上游 commit、Cargo.lock 校验值、源码/重链接书面 offer），不内置 rawler 源码。

## 0.3.x 及更早

本仓未保留逐版记录；`Cargo.toml` 只留下 0.3.0 → 0.4.0 的版本延续说明。
更早的变更史以 git 提交记录为准，不在此追补。
