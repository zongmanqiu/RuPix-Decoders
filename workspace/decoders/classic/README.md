# classic

Old raster formats that still appear in archives, installers and legacy
toolchains, implemented in Rust only.

`classic` is a published DLL, not a sub-crate of another tier. The directory
name, the package id and the DLL id are all `classic`; future growth follows
the same split rule as `doc` (a second DLL gets its own directory, never a
second list inside this one).

## Formats

| Member | Suffixes | Crate / method |
|---|---|---|
| `pnm` | `pnm ppm pgm pbm pam` | `image` (P1-P7) |
| `pcx` | `pcx pcc` | `image-extras` / `pcx` |
| `dcx` | `dcx` | first PCX page in the DCX container |
| `wbmp` | `wbmp` | `image-extras` / `wbmp` |
| `xbm` | `xbm` | `image-extras` / `xbm` |
| `xpm` | `xpm` | `image-extras` / `xpm` |
| `pict` | `pict pct pic` | `oxideav-pict` |
| `ilbm` | `ilbm lbm iff` | `oxideav-iff` |
| `sgi` | `sgi iris bw` | `image-extras` / `sgi` |

`rgb` / `rgba` stay with `raw`: they are the common SGI suffix but already
belong to the raw-pixel tier. `classic` never claims a suffix owned by
`common`, `modern`, `pro`, `raw`, `doc` or `doc-legacy`.

## Claim rule

`iv_probe` returns 100 only for content it recognizes. Binary formats use
their magic/header; text formats require the XBM/XPM declaration shape. When
the host passes `ext == NULL`, the same content checks apply, so a file can
still be found by a drag-and-drop probe without relying on its name.

## Build

```powershell
cd RuPix-Decoder\workspace\decoders\classic
cargo test --release -- --test-threads=1
cargo build --release
```

The output is `.temp/classic-target/release/classic.dll`; `.cargo/config.toml`
keeps it out of the source tree. The shared decoder build publishes it as
`classic_0.1.0.dll`.

## Limits

The shared `pro-support::check_dims` gate applies before pixels are accepted:
64 MP hard cap and the host-provided byte budget. PICT/IFF also receive the
same limits as decoder options so a hostile header fails before allocation.
All third-party decoders are called inside `guard`, so a malformed sample
becomes `ERR_CORRUPT` / `ERR_PANIC`, never a host crash.

## Sample pack

All 20 suffixes have a synthetic, CC0-1.0 sample generated by
`testdata/make_classic_samples.py` (see
[`CLASSIC-SAMPLES.md`](../../../testdata/CLASSIC-SAMPLES.md)). No third-party
image is bundled, so no per-image license has to be chased.
